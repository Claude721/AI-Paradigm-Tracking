# CIDiffuser 校准案例

## 这个案例真正贡献了什么

有效的部分不是某个固定段落结构，而是观察顺序：

1. 先站在读者熟悉的条件扩散训练与生成流程上；
2. 把整篇工作压成“在哪个接口加入了什么约束”；
3. 再问低分辨率模型中哪些动词仍然含混；
4. 只下钻会改变整体理解的接口；
5. 从这些接口自然推出验证问题和局限。

这比按 Semantic Encoder、SCM、DCEL、AdaGN、Loss 逐个介绍更容易形成可运行理解。

## 经原文校正的低分辨率模型

以条件扩散的生成链为坐标，CIDiffuser 并没有依据因果矩阵重新设计一张 noise map，也没有人为规定一条新的前向加噪路径。它先用有监督的 semantic encoder 把指定视觉属性与其他辅助信息分开，再用由标签和图像训练出的直接因果效应矩阵，经 SCM 把语义表示变成 `z_causal`。这个 `z_causal` 通过 AdaGN 作为条件进入去噪 U-Net；另一条 stochastic representation 负责保留细节。

运行时，用户修改 semantic latent 的目标属性，经 SCM 得到新的因果条件，DDIM 去噪器于是沿同一类扩散过程生成符合新条件的图像。可控性来自“**改变了去噪器看到的结构化条件，并保留非目标细节**”，不是“因果图直接定义了噪声轨迹”。

## 应当沿哪些理解结下钻

### 因果矩阵到底改变什么

- 疑问：它改写噪声、去噪路径，还是条件表示？
- 原文：`A` 进入 SCM，把 `epsilon_semantic` 变换为 `z_causal`；`z_causal` 再经 AdaGN 注入 U-Net。
- 模型更新：因果矩阵约束的是条件表示中的属性依赖，扩散模型负责把该条件实现为像素。

### 因果效应怎样被估计

- 疑问：模型是否从自然图像中自动发现了真实因果图？
- 原文：DCEL 使用标签、原图、反事实属性翻转和分类损失估计效应，并允许背景知识预先指定零边。
- 模型更新：这是有监督、带结构先验的模型内因果代理，不是无条件可识别的现实因果发现。

### 为什么局部编辑不会任意串扰

- 疑问：修改年龄时，为什么身份和非后代属性应保持？
- 原文：目标属性在 semantic latent 中被干预，SCM 只按其图关系传播；stochastic branch 和辅助表示保留其余生成信息。
- 模型更新：预期局部性来自“属性化表示 + 图约束传播 + 非语义细节旁路保留”的组合，不能只归因于 SCM。

### 最自然的边界问题

- 属性集合和人工指定的零边是否完整、互斥且覆盖真实生成因素；
- DCEL 的反事实分类代理是否真的去除了未观测混杂；
- 分布外属性组合中，AdaGN 条件能否压过训练数据的共现偏置；
- 结构化语义瓶颈是否牺牲了未标注属性和开放域泛化。

这些问题来自运行图中尚未闭合的接口，不是单独附加的一组通用“论文局限”。

## 错误示范的诊断

“因果矩阵构造 noise map，模型沿这张图去噪”是一条顺畅但错误的解释。它把三个不同对象混成了一个：

- SCM 中的属性依赖；
- U-Net 接收的条件表示；
- 扩散过程中的噪声状态与采样轨迹。

高分辨率心智模型不是细节越多越好，而是这些对象不再被同一个含混动词连接。

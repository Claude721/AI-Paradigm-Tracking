## 配置为何不再需要代码适配

请求协议按提供方预设与角色 REQUEST_OPTIONS 选择，不依赖模型名、固定地址或日历。换兼容 API 后只改本角色配置；特殊输出参数、extra_body 或不支持的参数也由配置覆盖。MAIN/SUB 不互相借模型或 Key，策略变化使相关缓存失效。

样本价格通过工作流 price_contracts JSON 输入，按实际角色校验模型、地址、当日 UTC 核验日期、最高原价、容量、完整输出与响应别名；没有匹配价格时在请求前停止。正常生产不要求样本价格，不把价格数据当作生产模型准入名单。详见[配置清单](CONFIGURATION_CHECKLIST.md)和[样本操作](ONE_ROUTE_ACCEPTANCE.md)。

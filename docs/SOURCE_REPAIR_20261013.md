## 修复内容

1. Meta：原 `/research/publications/` 的 45-byte 非内容响应继续记录，新增同源出版目录适配。只读取显式出版卡片及连续分页，不执行 JS。旧 URL 的大小写、点号保留；同页/跨页重复卡片保留原回执，输出按 URL 去重，不以“没有新 URL”或“日期很旧”停止。真正相同整页循环仍 pending。官方空尾页须同时核验同源 URL、PUBLICATION、精确页号、完整筛选条件、无下一页及明确无结果模板；首屏空响应、错误/歧义模板不能算成功零。`unfilteredResultsHits` 包含其他类型，不冒称已过滤论文总数。
2. 日期冲突：Meta 的同一论文存在不同标题大小写、发布日期。冲突事实全部保留，输出不选一个胜出的发布日期。所有显式日期均严格早于窗口开始日时只作窗口上界排除；任何日期可能落入本窗时须读一手正文核验。已有历史详情任务不因这个过滤删除。
3. 故障隔离：大型 Meta 目录读取前先完成并提交其他官方入口已经选中的详情。后续目录慢/取消不会让健康入口反复登记尝试却没有真正 HTTP，也不会吞掉已完成研究输入。
4. Gary Marcus / Zvi：保留原 RSS 与 `secondary_only` 身份，RSS 失败后允许同作者公开归档。核验 publication ID、稳定 URL、精确 `post_date`、署名和 audience，newest 分页到窗口边界；不登录、不解锁订阅、公开数据声明禁止 AI 抓取即停止。只解析双重 JSON 字面量，兼容实际没有结尾分号的页面，不执行脚本或尾随表达式。
5. 归档恢复：目录与每篇解析/过滤子回执独立保存；游标与实际对象基数一致，JSON 键排序不改变日期边界或输出顺序。缓存绑定注册 publication ID / 作者别名，旧身份不能冒充当前发布者。正文或一条署名失败只保留对应待办，健康同伴继续。
6. 公开作者：实际一篇 Gary 文章的 API `publishedBylines=[]`，同一公开文章明确提供 `<meta name="author" content="Gary Marcus">`。仅在同一文章 ID / URL / 标题 / 日期 / 发布者均匹配、唯一 HTML 作者与已登记别名精确一致时使用这个证据；缺失、陌生或歧义作者仍 pending，不从刊物名猜个人。
7. NYU：保留嵌套引号后的完整题名，歧义题名不猜。解析修复恢复出的显式 arXiv/DOI 可以重绑定同一引用 SHA 的历史 pending 对象，不删除旧任务、不合成 OpenAlex ID、不自动新增身份 API 请求；仍要求一手标题/作者/日期及落盘详情闭合。

四份研究 Skill 已核对；领域模型、Rubric、发布者/承接门、人物门与中文/链接编辑闸门均未放宽。配置没有增加新变量。源码策略签名使对应旧成功回执失效，但原来源范围签名不变。

全量代码检查还通过故障注入复现了取材转换层的局部异常向全局扩散：RawProject.extra 错结构、原生记录没有 evidence_type、Follow Builders 日期类型错误或无法序列化的记录，会在外层逐条校验前终止聚合。现把格式/嵌套字段/JSON 验收前置到聚合之前，坏记录逐条隔离；保留健康来源、原失败账本和真实数量，不放松技术 Rubric、时效、URL、CAS 或人工反馈保护。此项是本轮排查发现的潜在故障，不冒称它导致了本次 Runner 失败。

更新日期：2026-10-08。结论：工程候选已完成本轮系统性改造与离线验证，**生产 V0 尚未验收**。此前以成功发信或 Actions 绿色宣称可用的判断已撤回；没有范围与判断闭合的零条报告不构成业务结果。

## 1. 本轮交付的工程能力

- schema v8 固定研究批次，冻结窗口、seed、发现快照与覆盖账本；一个未完成批次跨进程恢复，不每次重扫并加入新一周材料。
- 原点、深挖、历史刷新有任务清单与版本回执；清单只增不减，刷新一次成功或无变化后不重复入队，运行中断另记尝试而非技术淘汰。
- 普通资格预筛默认 24 条，逐原点缓存健康结果；遗漏、重复或外来 ID 不牵连健康同伴。完整抽取仍是机制 Rubric，不以吞吐降低门槛。
- Technical Report 索引持久化，每个成功机制立即保存下游候选与父进度；慢同伴/取消不会吞掉结果，健康分片在同轮有预算时继续。解释改名不改变已索引机制身份，不强并同报告不同机制。
- 独立路线深挖默认并发 2；综合/人物检查点可在同一固定批次跨周复用，相关输入、策略或模型配置变化使其失效并重建可执行队列。
- 人物轨迹逐身份保存成功结果；错误 JSON、缺字段和非中文解释不能缓存完成。并行阶段失败会取消并等待在途同伴，不放任后台请求继续消耗。
- 研究窗口与真实指标观测时钟分开；续跑的新发布/增长不倒填原周。社区临时正文不写入发现、候选或任务恢复快照。
- 只在任务与详细覆盖全部闭合后入 outbox；父状态、真实 SQLite 队列与统计相互核对。报告/SMTP 独立恢复，确认后才登记交付。
- 有界自动预算续跑已实现但默认关闭：同批次、状态先上传、纯预算延期、次数/研究时间/已确认 tokens 上限；源故障、执行错误或未知中断用量需修复后人工继续。未设置远程变量、未触发 Actions。
- arXiv 含重试共享三秒请求间隔，尊重长 Retry-After；HTTP 200 错误 Atom、非 Atom 和重复分页拒绝记为成功空结果。OpenReview 参数修复仍需真实端点验收。

## 3. 真实阻碍：不能承诺下一次必定成功

最新附件 `logs_102211528694.zip` 执行 `2a979b5`，395 项旧离线门通过，恢复 386 条路线、12,132 条证据与 11 次路线交付；召回 1,236 原点/204 支持，约一小时后 13 候选/0 交付，仍发未完成邮件。只有 Actions 日志，没有同 run 的完整 audit 与状态 DB，不能精确计算每个阶段的重复率、误筛与真实迁移兼容性。

日志中的失败入口包括 OpenAI research index、Physical Intelligence research、TRI publications、xAI news 的 403/429，Z.ai blog 的 404，以及 Gary Marcus/Zvi Feed 的 403。本轮公开只读检查确认 Z.ai 博客根路径仍 404，sitemap 仅产品/账号页，不是等价研究索引；不能替换后假称研究覆盖恢复。其他公开端点检查亦未取得可交付的完整覆盖证据。未删除这些配置，少数失败仍阻断闭合。

单个适配器部分失败时续跑目前重试该适配器，不是每个 query/page 的独立持久化；如果真实生产某个来源永远无法在 600 秒内完成，需要据详细 audit 拆开其能力回执，而不能提高所有源超时赌成功。外部增强未进入综合检查点仍须重取临时正文，保留隐私边界；逐人物 API 内部及独立承接关系表、跨来源版本路线 alias 并非全部自动化能力。它们是否造成真实容量/质量阻断，需要副本回放测量，不宣称所有长期设计项已完成。

自动链默认关闭，所以大于一次预算的真实负载不会自行一天完成；开启额外 run 是成本选择，不能由代码重构擅自启用。默认四轮/四小时额度也不是对任意 workload 的完成保证。没有真实到达率、模型延迟/用量与误筛样本，不能给可信的 V0 日期或费用预测。

## 4. 进入生产 V0 的验收顺序

1. 提供最新同 run 的 audit artifact 与健康 state artifact（DB + state-meta），不需要 .env/密钥。在临时副本迁移，核对路线/证据/交付守恒、原点与任务版本及恢复次数。
2. 针对具体失败来源验证等价官方公开入口/协议。不删团队、Feed、待办或缩分母“修好”；确需缩研究范围时由用户明确决定，并建立新的声明范围。
3. 经用户授权后进行有界小样本真实 API 验收，先关闭邮件，记录延迟、用量和人工研究质量；再做保留旧状态的完整闭合、同窗恢复与去重验收。SMTP 发信需单独明确授权。
4. 校准单窗口真实工作量与可持续处理率，确定是否开启预算续跑及可接受额度。完整报告/空结论必须可解释，不靠每期强行非空。
5. 验收实际云端代码指纹、详细覆盖闭合、状态上传、报告质量、交付确认及后续计划窗口。当前没有执行这些真实流程。

3. 历史兼容：正式研究运行重开明确失败却已终结的候选；正常零结果、关闭入口及没有明确失败证据的旧记录不批量重开。保留交付历史、`last_reported_signature` 与 FIFO 身份，修复原子提交；状态/信源检查不执行该修复。综合检查点策略提升到 v2，旧策略结果不静默复用。

6. NYU 书目：持久化只增不减的书目身份清单；成功身份跨进程复用，低尝试次数优先，避免歧义首项阻塞后项。OpenAlex 仅补候选身份与原文入口，要求唯一精确标题、作者名/首字母对齐、引用年份一致及显式 arXiv/DOI URL；歧义、截断、同姓异人、无原文入口继续待办。仍须读取一手内容、作者与发布日期；索引发布日期、年份和修改日期不能冒充原文发布日期。

9. Tavily 成本：schema v9 新增 `provider_credit_periods` / `provider_credit_requests`。每进程先核验真实 UTC 月份账户用量，basic 搜索前原子预留 1 credit；明确实际扣费才能结算，取消/崩溃/未知用量不退款且停止本进程后续搜索。账户观察与本库预留取保守上界，状态随 artifact 跨 run 恢复，不把研究窗口日期用于计费月份。Smoke/平台验收共用独立用量协议，不导入生产采集器。
10. Qwen：仅读取官方研究组件使用的 `research.research-list` 与 `article/retrieval` 两个公开集合；核验身份/基数/重复/未来分页，健康条目保留，未知项 pending。读者入口按已核验前端 `/blog?id=<article.path>` 协议确定性构造并实际访问，再读与该身份匹配的单文章 API；不使用已失效的旧 canonical、不执行 JS、不访问内部 git_url。官方组件的 `extra.date` 必须与单文章 API 日期一致，旧 Hugo 日期冲突单独记录，不能改用 dateModified。
11. 官方详情闭合：原非零 link safety limit 只抓头部，却漏记尾项，可误写成功空覆盖；现为同窗口单调 URL 清单，失败/未尝试对象跨进程保留、低尝试次数优先、已完成正文复用。索引不再列出旧失败 URL 不能删任务，汇总零 pending 也不能掩盖逐页面 pending。单条解析/保存故障隔离自身，超时仍返回已提交健康同伴、来源保持 timed_out。未知发布时间不能用旧 dateModified 排除，明确未来发布日期不倒填冻结窗口。
12. 快照与修复兼容：原来源计划把 scope 与适配器签名混在一起，修复后同批次可能被误当作范围变化拒绝续跑。现分别存原公开入口/查询/窗口与适配器策略签名；修复只使对应来源旧成功回执失效，实际编排器也调用该重试规划。删入口/改窗口仍拒绝；旧官方快照须完整逐页身份及原窗口证明，数量相等不足。详情队列 v2 父记录仅存身份，正文/attempts/完成回执按 URL 原子保存，旧 v1 先保存全部子项再替换父记录，失败保留旧快照，不丢计数或任务。
13. NYU 恢复闭合：整合测试复现原 `primary_verified` 每次恢复都会被重置为 `resolved_url`，随即重开已完成详情；两条材料、每轮一条，第二轮仍只有一条结果且永远 partial。现保留回执并与当前策略的实际详情配对：正文日期/标题/作者符合才可复用，窗口外回执也须配对策略与日期。先保存详情再登记书目核验，核验保存失败不提前改内存完成；正文已保存但上游回执失败可从该正文补齐，不重复 HTTP。没有下游详情、旧策略或不同书目误指同一原文不能冒充完成；该修复不替代真实书目解析。
14. 尝试登记隔离：原详情尝试登记异常会跳过该索引所有选中详情；现在只隔离写入失败的 URL，不发出其 HTTP，健康同伴继续。尝试先保存成功才更新内存；失败不伪造已开始请求或删除任务。全部登记失败明确 `detail_checkpoint_failed`，不能标为 `no_recent_links`；新增两项故障注入覆盖健康同伴与全部失败。

四份研究 Skill 已核对；综合与写作契约同步社区/启用学术增强的执行状态边界。Rubric、发布者、外部承接、人物和中文/链接质量门槛均未放宽。当前 schema v9 自动迁移 v1–v8，保留历史任务、交付与研究结果；损坏/缺失 v9 额度账本不能冒充健康恢复。

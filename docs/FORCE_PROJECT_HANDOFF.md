# 受力分析项目后台交付

周任务在冻结交付完成后运行 `scripts/force_handoff.py`，将原报告和对应的结构化记录发送到受力分析站点的持久后台。这里只复用已经生成的研究结果。

独立 `.github/workflows/force-handoff.yml` 每周一12:00（Asia/Shanghai）补收。手动触发读取最近一份完整的既有交付，验证后台写入与重复交付处理。云任务使用 GitHub 短期只读凭据获取原报告、状态及审计制品，核对源运行及提交后发送，不启动研究、模型、搜索或邮件。

仓库变量 `FORCE_SITE_URL` 指向受力分析站点。`FORCE_SITE_INGEST_TOKEN` 是专用于该后台接收接口的仓库密钥。密钥值仅在运行时注入。

主周任务中的发送失败单独告警，研究和邮件交付状态继续保留。后续云端补收按冻结交付ID重试。后台原件、证据及研究候选均以内容摘要封存，重复发送复用原记录，冲突不会覆盖历史。

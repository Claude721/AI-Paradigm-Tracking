## 人工验收为什么否决

原文将不同模型、不同环境下的局部能力和简化实验分开，并将完整小模型能力保留为未来预测。程序草稿把它们合成了已经成立的端到端能力，还写出了原文未证明的具体运行实例。结构、中文长度和 URL 通过，并不证明事实与条件没有被误写。

人物同样存在契约缺口：两位署名已恢复，但没有最低职业背景或已完成联系检索。旧 verified_organization_attribution 把所有 established + official_* 博客都当成可单独组织归因，隐藏了未核验自然人。它使该样本获得自动 route_quality_passed，但并不符合项目人物边界。这是代码逻辑问题，不应要求重配全部 API Key。

同一材料两轮业务分类不同，输入发生了变化且模型判断也有波动；不能据此断言修复作者字段就证明报告正确。人工核对一手事实和人物契约仍是必要的验收步骤。本次不发布或发送不合格草稿。

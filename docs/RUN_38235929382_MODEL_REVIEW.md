修复：共享客户端只对已核验的官方北京 Qwen 3.7 Plus 显式配置 `enable_thinking`，默认关闭；原输出数值改为思考与回答总上限。Smoke、生产各阶段和单路线一致；不自动涨 tokens/时限，不迁移模型，不向未知模型/代理发送猜测参数。模式变化使抽取、综合、人物缓存失效；有界验收固定非思考模式。真实非思考判断质量仍需复测和人工核验，离线请求契约不替代质量证据。
